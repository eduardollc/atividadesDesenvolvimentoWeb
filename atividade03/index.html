.03

Forms

Um formulário HTML é usado para coletar informações do usuário. A entrada do usuário é geralmente enviado a um servidor para processamento.

Elemento <form>

O elemento <form> é um contêiner para diferentes tipos de elementos de entrada, como: campos de texto, caixas de seleção, rádio botões, botões de envio, etc.

Elemento <imput>

Um <imput> elemento pode ser exibido em de muitas maneiras, dependendo dotype atributo. Exemplos:

Tipo Descrição
<input type="text"> Exibe um campo de entrada de texto de linha única
<input type="radio"> Exibe um botão de opção (para selecionar uma das muitas opções)
<input type="checkbox"> Exibe uma caixa de seleção (para selecionar zero ou mais de muitas opções)
<input type="submit"> Exibe um botão de envio (para enviar o formulário)
<input type="button"> Exibe um botão clicável

Elemento <label>

O elemento <label> define um rótulo para um campo do formulário. Ele ajuda o usuário a identificar a finalidade de cada campo e melhora a acessibilidade da página.

O atributo for do elemento <label> deve ter o mesmo valor do atributo id do campo ao qual está associado.

Campos de texto

O <input type="text"> define um campo de entrada de texto de linha única, permitindo que o usuário digite informações.

Exemplo de codigo

<form>

<label for="pname">Primeiro nome:</label><br>

<input type="text" id="pname" name="pname"><br>

<label for="sname">Segundo nome:</label><br>

<input type="text" id="sname" name="sname">

</form>




Botões de rádio

O <input type="radio"> define um botão de opção. Ele permite que o usuário selecione apenas uma opção de um grupo de alternativas.

Caixas de seleção

O <input type="checkbox"> define uma caixa de seleção. Ela permite que o usuário selecione nenhuma, uma ou várias opções de um grupo.

O botão Enviar

O <input type="submit"> define um botão para enviar os dados preenchidos no formulário. O atributo action do elemento <form> especifica o destino para o qual os dados serão enviados.
