Forms

Um formulário HTML é utilizado para coletar informações do usuário. Os dados podem ser enviados para um servidor para processamento.

Elemento <form>

O elemento <form> é um contêiner para campos de entrada, caixas de seleção, botões de rádio e botões de envio.

Elemento <input>

O elemento <input> permite diferentes tipos de entrada, definidos pelo atributo type.

Tipo Descrição
text Campo para digitar texto em uma linha.
radio Permite selecionar uma opção de um grupo.
checkbox Permite selecionar zero ou mais opções.
submit Cria um botão para enviar o formulário.
button Cria um botão clicável.

Elemento <label>

O elemento <label> define um rótulo para identificar um campo. O atributo for deve corresponder ao id do campo.

Campos de texto

O <input type="text"> permite que o usuário digite informações em uma linha.

Exemplo de código

<form>

<label for="nome">Nome:</label>

<input type="text" id="nome" name="nome">

</form>





Botões de rádio

O <input type="radio"> permite selecionar apenas uma opção dentro de um grupo que compartilha o mesmo atributo name.

Exemplo de código

<input type="radio" name="numero" value="01">

<label>01</label>

<input type="radio" name="numero" value="02">

<label>02</label>

Caixas de seleção

O <input type="checkbox"> permite selecionar várias opções independentemente.

Exemplo de código

<input type="checkbox" id="html" name="html">

<label for="html">HTML</label>

<input type="checkbox" id="css" name="css">

<label for="css">CSS</label>

O botão Enviar

O <input type="submit"> cria um botão para enviar os dados do formulário. O atributo action define o destino do envio.

Exemplo de código

<form action="/processar.php">

<input type="submit" value="Enviar">

</form>

CSS Grid

O CSS Grid é um sistema de layout que organiza os elementos em linhas e colunas. Ele facilita a criação de estruturas com duas dimensões.

Propriedades principais

Propriedade Descrição
display: grid Ativa o layout Grid.
grid-template-columns Define as colunas do layout.
grid-template-rows Define as linhas do layout.
gap Define o espaço entre os elementos.

Exemplo de código

.grade {

  display: grid;

  grid-template-columns: repeat(3, 1fr);

  gap: 10px;

}

CSS Flexbox

O Flexbox é um sistema de layout que permite distribuir, alinhar e organizar elementos em uma linha ou coluna.

Propriedades principais

Propriedade Descrição
display: flex Ativa o Flexbox no contêiner.
justify-content Alinha os elementos no eixo principal.
align-items Alinha os elementos no eixo transversal.
flex-wrap Permite que os elementos quebrem para outra linha.
gap Define o espaço entre os elementos.

Exemplo de código

.flex {

  display: flex;

  justify-content: space-around;

  align-items: center;

  gap: 10px;

}

Containers

Um container é um elemento que agrupa outros elementos e ajuda a organizar o conteúdo da página. Em HTML, a tag <div> é frequentemente usada para criar contêineres genéricos.

Exemplo de código

<div class="container">

  <h3>Título</h3>

  <p>Conteúdo do container.</p>

</div>

Meu container

Este conteúdo está agrupado dentro de uma div, que pode receber estilos de largura, espaçamento, borda e cor de fundo.
