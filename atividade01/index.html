Imagens

A tag HTML <img> é utilizada para inserir imagens em uma página web. Ela utiliza o atributo src para indicar o caminho da imagem e o atributo alt para fornecer uma descrição alternativa, exibida caso a imagem não possa ser carregada e utilizada por leitores de tela. Você também pode definir a largura width e a altura height da imagem para controlar suas dimensões.

Exemplo de código

<img src="images/claudeComputer.png" alt="Claude" style="width: 120px; height: 100px;">

Classes e IDs

Em HTML, os atributos class e id são utilizados para identificar elementos e aplicar estilos com CSS. O atributo class pode ser utilizado em vários elementos, enquanto o atributo id deve identificar um único elemento na página.

Exemplo de classe

<p class="destaque">Este parágrafo utiliza a classe destaque.</p>

Exemplo de ID

<h2 id="">Este parágrafo utiliza o id paragrafo.</h2>

Estilização com CSS

.destaque { color: purple; } #paragrafo { color: blue; }

Este parágrafo utiliza a classe destaque.
