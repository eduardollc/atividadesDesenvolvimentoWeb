Tabelas

A tag HTML <table> é utilizada para criar tabelas. A tag <tr> representa uma linha, a tag <th> representa um cabeçalho e a tag <td> representa uma célula com informações.

Exemplo de código

<table> <tr><th>Nome</th><th>Curso</th></tr> <tr><td>Ana</td><td>Sistemas</td></tr> </table>
Nome Curso
Ana Sistemas de Informação
Pedro Ciência da Computação

Layout HTML

O layout HTML define a organização das diferentes partes de uma página. Para isso, podemos utilizar elementos semânticos que representam o cabeçalho, a navegação, o conteúdo principal, as seções e o rodapé. Entre esses elementos estão as tags <header>, <nav>, <section>, <article>, <aside> e <footer>.

Exemplo de código

<header>Cabeçalho</header> <nav>Navegação</nav> <main> <section>Conteúdo principal</section> <aside>Conteúdo complementar</aside> </main> <footer>Rodapé</footer>

Exemplo visual de layout

HEADER — Cabeçalho
NAV — Navegação

SECTION

Representa uma seção do conteúdo.

ARTICLE

Representa um conteúdo independente, como um artigo.

ASIDE

Apresenta conteúdo complementar.

FOOTER — Rodapé

Listas

As listas são utilizadas para organizar informações. A tag <ul> cria uma lista não ordenada, enquanto a tag <ol> cria uma lista ordenada. Cada item da lista é representado pela tag <li>.

Exemplo de lista não ordenada

<ul> <li>HTML</li> <li>CSS</li> </ul>

Materiais para estudar

  • HTML
  • CSS
  • JavaScript

Exemplo de lista ordenada

<ol> <li>Planejar</li> <li>Desenvolver</li> </ol>

Etapas de um projeto

  1. Planejar
  2. Desenvolver
  3. Testar

Block e Inline

Os elementos block normalmente ocupam toda a largura disponível e começam em uma nova linha. Já os elementos inline ocupam apenas o espaço necessário e permanecem na mesma linha do texto.

Exemplo de código

<div>Elemento block</div> <p>Texto com <span>inline</span>.</p>

Links

A tag HTML <a> é utilizada para criar links que permitem navegar entre páginas ou acessar outros sites. O atributo href define o endereço para o qual o usuário será direcionado quando clicar no link.

Exemplo de código

<a href="https://www.google.com">Acessar Google</a>

Exemplo de link: Acessar Google
